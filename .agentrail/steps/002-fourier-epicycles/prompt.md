start-here step 2: demos/fourier-epicycles. A closed curve (presets: a heart, a star, a square, a digit outline, or a path the user draws) sampled at N points as two Float vectors x, y; its discrete Fourier transform computed as one outer product (the N x N table of angles 2 pi k n / N, then cos/sin times the samples, reduced) giving each frequency's amplitude and phase; the epicycles: circles on circles, sorted by size, drawn chaining and tracing the curve as time runs; a slider for how many circles (the reconstruction with the first K terms, the error shrinking). No loops: the transform and the reconstruction are table + reduce. Tests: the inverse transform returns the samples; a single circle's transform is one term; Parseval (energy equal); agreement with a direct Rust DFT. CLI + reg-rs baselines, web, docs, live.
