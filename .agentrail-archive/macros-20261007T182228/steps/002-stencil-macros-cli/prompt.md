New demo stencil-macros: a user macro library Stencil.xtlm that turns a kernel written as a picture of numbers into rotation arithmetic at expansion time (zero entries vanish, ones lose their multiply); stencil-macros.xtl applies several kernels (blur, edges, Laplacian diffusion) to a picture. CLI goldens for the run and for xetal expand; README; asks for whatever X_eTaL lacks (named workarounds).
