programdemos/ca-lab/ca-lab.xtl

A cellular automata lab. Every rule here is a lookup table: each cell's neighborhood becomes a number, by rotations and arithmetic over the whole array, and the number picks the cell's next state from the table (s_elect). Changing the rule is changing the table. Run it with "xetal run demos/ca-lab/ca-lab.xtl"; it prints Rule 30 and Rule 90 as sixteen-generation boards, Life, Brian's Brain and Wireworld, each drawn with characters. The live page lets you edit the table and the board, one and two dimensions each their own view: https://softwarewrighter.github.io/X_eTaL-demos/ca-lab/
