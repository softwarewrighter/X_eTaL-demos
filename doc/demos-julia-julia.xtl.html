programdemos/julia/julia.xtl

Julia sets and the Mandelbrot set from one function, u:i_terate. Both iterate z becoming z * z + c and count the steps z stays within 2 of the origin. For the Mandelbrot set, c is the grid of points and z starts at 0; for a Julia set, z starts at the grid and c is one number, which scalar extension spreads over the whole grid: the step is written once and works both ways. X_eTaL has no complex numbers yet, so z and c are each a real and an imaginary part (see the demo's README Workarounds). Run it with "xetal run demos/julia/julia.xtl"; it prints the grid's shape, a Julia set (c = -0.8 + 0.156i) drawn with characters, and the Mandelbrot set from the same function. The live page lets you pick c on the Mandelbrot map and watch the Julia set change: https://softwarewrighter.github.io/X_eTaL-demos/julia/
