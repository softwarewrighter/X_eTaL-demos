1⍝!/usr/bin/env xetal 2⍝# A cellular automata lab. Every rule here is a lookup table: each 3⍝# cell's neighborhood becomes a number, by rotations and arithmetic 4⍝# over the whole array, and the number picks the cell's next state 5⍝# from the table (s_elect). Changing the rule is changing the table. 6⍝# Run it with "xetal run demos/ca-lab/ca-lab.xtl"; it prints Rule 30 7⍝# and Rule 90 as sixteen-generation boards, Life, Brian's Brain and 8⍝# Wireworld, each drawn with characters. The live page lets you edit 9⍝# the table and the board, one and two dimensions each their own 10⍝# view: https://softwarewrighter.github.io/X_eTaL-demos/ca-lab/ 11 12⍝# -- one dimension: Wolfram's elementary rules. 13⍝# u:b_its rule: a rule number's 8 bits are the table: the next state 14⍝# for each of the 8 neighborhoods (left, center, right), numbered 15⍝# 4 * left + 2 * center + right. 16ᵘb̲its ← { rule → (rule d̲iv 2 ^ o̲ffsets 8) m̲od 2 } 17⍝# u:r_ow tbl r: the next row. Each cell's neighborhood number, by 18⍝# rotation, looks up its next state in the table (1 + because 19⍝# s_elect counts from 1). 20ᵘr̲ow ← { tbl r → (1 + (4 × -1 o̲- r) + (2 × r) + 1 o̲- r) s̲elect tbl } 21⍝# u:g_row tbl h: the history grows downward: rotate the rows up one, 22⍝# and put the next row (of the last one) at the bottom.
