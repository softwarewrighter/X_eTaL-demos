programdemos/mandelbrot/mandelbrot.xtl

The Mandelbrot set as arrays: every point c of a view iterated at once, z becoming z * z + c, counting the steps each point stays within 2 of the origin. X_eTaL has no complex numbers yet (an ask: see the demo's README Workarounds), so z and c are each two Float arrays, their real and imaginary parts. Run it with "xetal run demos/mandelbrot/mandelbrot.xtl"; it prints the shapes of c and of the stepped state, the set drawn with characters, and one point's orbit (its real parts, then its imaginary parts). The live page steps k and lets you click a point for its orbit: https://softwarewrighter.github.io/X_eTaL-demos/mandelbrot/

One step for every point at once

ᵘs̲tep : (Float, Float, Float) -> (Float, Float, Float)

function · line 52

u:s_tep (zr, zi, counts): the state is a tuple of three same-shaped arrays (z's real part, its imaginary part, and the count of steps spent inside), taken apart by the pattern and given back as a new tuple; no more packing them into one array (D7, landed). One step computes z * z + c everywhere, keeps z where the point has already left the disk |z|^2 > 4 (the mask inside), and adds inside to the count.

ᵘs̲tep ← { (zr, zi, counts) →
  inside ← f̲loat 4 ≥ (zr × zr) + zi × zi
  a ← (inside × cr + (zr × zr) − zi × zi) + (1 − inside) × zr
  b ← (inside × ci + 2 × zr × zi) + (1 − inside) × zi
  (a, b, inside + counts)
}
