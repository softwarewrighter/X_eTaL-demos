programdemos/fourier-epicycles/fourier-epicycles.xtl

Fourier epicycles: any closed curve is a sum of circles turning at whole-number speeds. Its points z = x + i y go through a discrete Fourier transform, written as two matrix products with the cosines and sines of one outer product of angles; each frequency is a circle, and the circles, strongest first, chained end to end, trace the curve. A running sum along the chain gives, at once, the curve rebuilt from the first 1, 2, 3, ... circles. Run it with "xetal run demos/fourier-epicycles/fourier-epicycles.xtl"; it prints the strength of each frequency, the four strongest speeds, and the mean error rebuilt from 1, 2, 4, 8 and all 16 circles. The live page lets you pick or draw a curve and slides how many circles trace it: https://softwarewrighter.github.io/X_eTaL-demos/fourier-epicycles/
