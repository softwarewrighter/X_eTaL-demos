1⍝!/usr/bin/env xetal 2⍝# Fourier epicycles: any closed curve is a sum of circles turning at 3⍝# whole-number speeds. Its points z = x + i y go through a discrete 4⍝# Fourier transform, written as two matrix products with the cosines 5⍝# and sines of one outer product of angles; each frequency is a 6⍝# circle, and the circles, strongest first, chained end to end, 7⍝# trace the curve. A running sum along the chain gives, at once, the 8⍝# curve rebuilt from the first 1, 2, 3, ... circles. Run it with 9⍝# "xetal run demos/fourier-epicycles/fourier-epicycles.xtl"; it 10⍝# prints the strength of each frequency, the four strongest speeds, 11⍝# and the mean error rebuilt from 1, 2, 4, 8 and all 16 circles.
