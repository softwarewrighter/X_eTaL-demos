programdemos/xetal-pipes/xetal-pipes.xtl

Unix pipes in X_eTaL: the arrays inside the stages (stages/*.xtl), shown on sample.txt. A stage reads standard input as one text; here the same text comes from the file. Every character is numbered by its line, so choosing lines is a mask and reordering them a grade: no loop over lines anywhere. Run it with "xetal run demos/xetal-pipes/xetal-pipes.xtl"; it prints the first line's character-to-line numbers, the counts xetalwc would give, where "lazy" starts and which lines it is on (grep), the padded lines' shape and which lines uniq keeps, and each line's rank and the text sorted by it. No live page: command line only (see the stages, xetalcat and friends, in the demo's README).
