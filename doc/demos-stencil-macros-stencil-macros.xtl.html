programdemos/stencil-macros/stencil-macros.xtl

Stencils by macro: image kernels written as pictures of numbers, and a macro library of our own (Stencil.xtlm, beside this file) that turns each into rotation arithmetic when the program is expanded. A 0 in a kernel writes no code at all and a 1 no multiply, so blur, edges, sharpen, emboss and heat each cost exactly their nonzero numbers. Run it with "xetal run demos/stencil-macros/stencil-macros.xtl"; it prints the totals a kernel keeps (blur and heat move the picture's total without changing it, edges sum to 0), then the picture and each result drawn with characters. See what the program becomes: "xetal expand demos/stencil-macros/stencil-macros.xtl". The live page lets you edit a kernel and see its expansion: https://softwarewrighter.github.io/X_eTaL-demos/stencil-macros/
