programdemos/image-pipeline/image-pipeline.xtl

An image pipeline as array programs: a picture built from masks, blurred, its edges found with the Sobel kernels, thresholded, and shrunk by max-pooling. Every 3 x 3 filter is the same two steps: the stack of the nine shifted copies of the image (its windows), then the kernel times the stack, summed. Run it with "xetal run demos/image-pipeline/image-pipeline.xtl"; it prints the windows' and the pooled map's shapes, then the picture, the edge strength, the edges and the pooled edges, each drawn with characters. The live page lets you edit the kernels and pick a picture, and click a pixel for its window times each kernel: https://softwarewrighter.github.io/X_eTaL-demos/image-pipeline/
