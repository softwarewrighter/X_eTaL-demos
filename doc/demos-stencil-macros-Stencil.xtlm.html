macro librarydemos/stencil-macros/Stencil.xtlm

Stencils written as pictures: a macro library. A kernel is written as its numbers, row by row (3 x 3, 5 x 5, ...); when the program is expanded, the macro writes the arithmetic the kernel stands for, one term per number that is not 0: the array moved by that number's offset from the center (a rotation, so the edges wrap) times the number. A 0 writes nothing and a 1 writes no multiply, so the code does exactly the work the kernel asks for.
